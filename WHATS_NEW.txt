NOTE ABOUT ZIP SIZE
The original GitHub download included compiled __pycache__ files. Those caches
are not program source and Render regenerates them automatically. They are
intentionally excluded from this clean deployment ZIP. ghost_hub.py and all
required templates, dependencies, Render configuration, and helper files are
included.
